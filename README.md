# Thesis-LivioVanCauter
This github contains all data, models, and files used in the construction and analysation of the different chapters

The repository is structured as follows: 

• Data: Raw and processed experimental datasets from Reizman et al. and
Perera et al., including all curated input files used for model training and
validation. Files for exploratory data analysis on the original datasets.

• Quantum chemistry: All output and xyz files for molecular and mechanistic
quantum chemical calculations.

• Microkinetic model: Scripts and models used for the microkinetic model.

• Machine learning: Scripts for baseline and hybrid mechanistic ML model construction.

• Optimization: Scripts and output files for the grid search reaction condition
optimization.

• Packages: Contains all packages for specific environements used in the construction/running of the different files
